# بوابة التشغيل: المرحلة التالية من تحديث الواجهة

توسيع لغة التصميم من الموقع العام إلى **بوابة التشغيل التجريبية** دون المساس ببياناتها أو الصلاحيات أو الطلبات الشبكية. البوابة لها واجهة عربية أولًا ولغة إنجليزية ووضع داكن، ولا تُبنى ضمن Astro؛ لهذا أضيف ملف `portal/public/editorial.css` مستقلًا بعد `app.css` بدل استيراد أصول الموقع العامة أو جعل البوابة تعتمد على بناء الموقع.

## المنفذ

- شاشة الدخول بسطحين واضحين: لوحة تعريف داكنة، ونموذج دخول أبيض/داكن مع نفس ترتيب الحقول. نسخة الهاتف عمودية، وبطاقة «بيئة تجريبية/إنتاج» متباينة القراءة في الوضعين.
- في الشاشات التشغيلية: عنوان صفحة بفاصل واضح، بطاقات مؤشرات ذات خطوط تمييز هادئة، جداول قابلة للمسح، وروابط تنقل نشطة بحد ظاهر بالإضافة للون الخلفية.
- أدوات العمل (زر، تبويب، حقل، بطاقة) أخذت شكلًا متسقًا مع الموقع؛ **ألوان الحالات** «نجاح/انتظار/خطأ» وتعريفات صلاحيات الأدوار والبيانات الأصلية لم تتغير. لم نُنشئ أي نسبة إنجاز أو معلومة طالب افتراضية جديدة.
- RTL والوضع الداكن، التباين في إشعار الدخول، عرض الهاتف، وتقليل الشفافية مستوعبة. لا أنيميشن جديدة؛ تعمل إعدادات تقليل الحركة الحالية.
- فحص الإنتاج شمل تقديم ملف CSS الجديد برؤوس الأمان نفسها. `npm run test:portal`: ‏166 اختبارًا ناجحًا. فحص بصري على جهاز حقيقي وقارئ شاشة ما زال مطلوبًا قبل الإطلاق.

## ما لم يُنفذ

هذه مرحلة واجهة فقط؛ البوابة **ليست جاهزة للإنتاج** لمجرد تحديث شكلها. لا مدفوعات فعلية ولا واتساب تلقائي ولا جلسات فيديو فعلية. لا تُرفع مراجع `public/pics` كأصول للبوابة لغياب إثبات الترخيص التجاري.

**تدقيق الهاتف:** أزيل الحد الأدنى الثابت `320px` من شبكة بطاقات البوابة عند عرض هاتف `320px` حيث يترك الحشو الداخلي أقل من ذلك؛ كما أصبحت أعمدة المؤشرات قابلة للانكماش دون تمديد الصفحة أفقيًا. الاختبار البصري في متصفح حقيقي ما زال مطلوبًا للتحقق من كل الصفحات.
