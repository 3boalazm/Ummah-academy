# Academy illustrations

Added 2026-10-15 for the editorial-cartoon visual refresh:

- `hero-learning.webp`: AI-generated illustration of an adult learner attending an online lesson. Used in the homepage and course templates that select the hero artwork.
- `kids-learning.webp`: AI-generated illustration of two school-age learners studying together. Used by the kids track, homepage audience panel and corresponding course artwork.

These are illustrative scenes, not photographs of actual students, teachers or the academy's classroom software. No testimonial or endorsement is implied. Artwork is decorative in the templates (`alt=""`); surrounding translated text provides the actual programme information.

Source generations were optimized to WebP (approximately 100 KB each). Astro generates responsive derivatives with intrinsic dimensions; homepage hero retains eager/high-priority loading and other images retain lazy loading. Existing original artwork remains available in this folder.
